# DigiNova Plus

A premium WordPress theme for digital products and SaaS marketplaces — built for selling software, apps, HTML templates, plugins, and other digital products.

## Features

- Fully compatible with **Elementor**, **WooCommerce**, and **Easy Digital Downloads**
- Dark mode support
- RTL language support
- Marketplace-ready layouts for digital/SaaS products

## Details

| | |
|---|---|
| Requires WordPress | 6.0+ |
| Tested up to | 6.6 |
| Requires PHP | 8.0+ |
| License | Envato Regular/Extended License |

## Structure

```
diginovaplus/          # Theme files
diginovaplus-core/     # Companion plugin (Elementor widgets, custom functionality)
```

## Installation

1. Upload and activate the `diginovaplus` theme via **Appearance → Themes**.
2. Install and activate the `diginovaplus-core` plugin for full functionality (Elementor widgets, custom post types).
3. Import demo content and configure pages as needed.
